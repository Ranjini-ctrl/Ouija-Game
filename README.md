# Ouija Game

A haunted-themed static website with a landing page, ghost rules, a scanner, a Ouija interaction page, and a ghost rock-paper-scissors game.

## Pages

- `index.html` - Landing page with welcome screen and audio.
- `home.html` - Rules and warning page for the ghost experience.
- `scan.html` - Ghost scanner page with radar animation and transition flow.
- `ouija.html` - Spirit question page with suggested questions and ghost replies.
- `game.html` - Ghost-themed Rock Paper Scissors game with score tracking.

## Features

- Responsive layout for desktop and mobile devices.
- Audio background with user interaction support.
- Ghost-themed UI styling and animations.
- Mobile-friendly button and input layouts.

## Usage

1. Open `index.html` to start.
2. Click "Start Game" to proceed to the rules page.
3. Follow the flow through `scan.html` to `ouija.html` and `game.html`.

## Notes

- The site is designed as a static HTML/CSS/JavaScript experience.
- Adjust image/audio file paths if assets are moved.
